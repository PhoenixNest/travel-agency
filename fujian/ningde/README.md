## 2. 宁德霞浦核心看点与适老特色

1. **大京沙滩 & 高罗海滩（国家级天然优质金沙滩）**：
   - 大京沙滩长达 3000 米，宽 200 余米，沙质金黄细腻，坡度平缓，避风性好；
2. **东壁村海景日落栈道**：
   - 沿崖壁修建的纯平海景木栈道，观赏夕阳将万亩滩涂与海面染成金紫色的世界级摄影大片；
3. **三沙光影小镇 & 花竹日出**：
   - 专车直达观景台，免爬山，远眺浮鹰岛与日出朝霞；
4. **霞浦鲜甜海鲜与地道闽东小吃**：
   - 霞浦剑蛏、碎螺、红膏鲟、闽东清蒸大黄鱼、地瓜杯。

## 2. 福州长乐核心看点与适老特色

1. **长乐下沙海滨度假村（海螺塔金沙滩）**：
   - 拥有长达数公里的纯净天然沙滩与标志性礁石海螺塔，沙滩极其宽阔平整，海风宜人；
2. **滨海新城东湖数字小镇与万亩防护林**：
   - 全程平坦无障碍沿湖绿道与海滨森林步道，负氧离子充沛；
3. **漳港“天下第一海蚌”非遗美食**：
   - 长乐漳港海蚌（西施舌）为国宴级极品珍馐，肉质脆嫩、味道极鲜；品尝正宗福州肉燕、鱼丸与鸡汤汆海蚌，极致适老养生。

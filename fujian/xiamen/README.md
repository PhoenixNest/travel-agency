# 福建厦门琴岛世遗与黄厝海滩度假方案 (4D3N)

## 严选四要素海景住宿（≤ ¥300/晚）

- **首选**：**桔子酒店(厦门国际会展中心高雄路店)**（华住会，门牌：思明区高雄路1号，房型：环岛路观景海景房，参考价：¥259~299/晚）
- **备选**：**汉庭酒店(厦门大学店)**（华住会，门牌：思明区思明南路497号，房型：高楼层海景房，参考价：¥219~269/晚）
